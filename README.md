# SUPREME

Браузерный семплер: пять пэдов, фоновый трек с кроссфейдом и аудиореактивный WebGL-фон.

## Запуск

Требуется Node.js. Установка зависимостей не нужна.

```sh
npm start
```

Откройте http://127.0.0.1:4173.

Пэды: A, S, D, F, G или нажатие мышью. Фоновый трек запускается кнопкой воспроизведения. Семплы проигрываются целиком.

## GitHub Pages

В Settings → Pages выберите Deploy from a branch, ветку main и папку / (root). Приложение работает как статический сайт; сервер Node.js для Pages не нужен.

Аудиофайлы находятся в Samples/Restik. Лицензия на их распространение не предоставляется этим репозиторием.

## Сцены

Каждая папка в Samples — отдельная сцена. Один файл с BGM в названии используется как фон (без учёта регистра); остальные аудиофайлы распределяются по пэдам по алфавиту. Имена файлов отображаются полностью. После замены звуков выполните npm run scenes и отправьте файлы вместе со scenes.json на GitHub. При npm start список обновляется автоматически.
